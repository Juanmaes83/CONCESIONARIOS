# CONCESIONARIOS — Adaptación desde Restaurante Premium

## Objetivo

Este proyecto parte del clon técnico de `WEB-RESTAURACI-N-PREMIUM-DIN-MICA` rama `class7-dish-journey-premium`.

No se busca construir un restaurante. Se reutiliza la arquitectura didáctica y visual del restaurante para crear una web premium de concesionarios con panel personalizable.

## Equivalencias de producto

- Restaurante / marca gastronómica → concesionario premium.
- Platos signature → vehículos destacados.
- Dish Journey → Vehicle Journey.
- Origen / atmósfera / chef / reserva → diseño / prestaciones / experiencia / cita.
- Ficha gastronómica → ficha técnica + emocional del coche.
- Reserva mesa → solicitar prueba / contacto comercial.

## Reglas de imagen

- Usar coches premium tipo Tesla como primera línea visual.
- Imágenes recortadas, sin fondo o fondo transparente cuando sea posible.
- No generar más de 2 imágenes del mismo coche/plano.
- Evitar series repetitivas del mismo prompt.
- Priorizar variedad real: frontal 3/4, lateral hero, interior, detalle óptica, detalle llanta.
